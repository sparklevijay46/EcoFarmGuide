# EcoFarm Guide
Mini project for the Community Service Project:
"Eco-Friendly Horticulture and Nursery Management Practices"

## Files
- index.html — main website
- style.css — responsive design
- script.js — interactive tools, crop popups, language toggle and saved checklist

## Run
Open index.html in any browser. No server or database is required.

## Customize
Replace the gallery placeholders in index.html with your real CSP photographs.
You can also add more crops and Telugu translations in script.js.
